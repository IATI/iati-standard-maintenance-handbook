==========
Deployment
==========

Once a proposal has passed, the final step is to deploy the changes. 

iatistandard.org
----------------

The first place to deploy is iatistandard.org; this updates the official reference and provides assets that other tools use. 

First, update the SSOT. See https://github.com/IATI/IATI-Standard-SSOT and https://github.com/IATI/IATI-Internal-Wiki/blob/main/IATI-Standard-Website/SSOT_Updates.md

Then, update the IATI reference. See https://github.com/IATI/IATI-Reference-Generator

Then, deploy to dev.iatistandard.org via https://dev.iatistandard.org/cms/pages/88/edit/ (see the update buttons at the bottom of the page)

Review the output, then deploy to iatistandard.org via https://iatistandard.org/cms/pages/88/edit/

Other tools
-----------

Several other tools use the IATI Standard. Review the tools that might be affected by the change and check with colleagues if they need to be updated.
